# Diagnóstico operativo de 25 preguntas

Demo genérica de Blastup Partner para explorar madurez operativa en cinco áreas: procesos, datos, herramientas, equipo y medición. Ejecuta python -m http.server 8000 en este directorio, abre http://localhost:8000 y responde las 25 preguntas. El servidor local solo entrega archivos; no hay cuenta, IA ni almacenamiento de respuestas.

**Web oficial:** https://blast-up.com

## Alcance

Cada respuesta suma 0 (no), 1 (parcialmente) o 2 (sí). El porcentaje total y los porcentajes por área son descriptivos. Se muestra primero el área con menor puntuación para orientar una conversación; los empates siguen el orden del cuestionario. La puntuación no es un diagnóstico profesional ni identifica automáticamente una solución.

Esta versión fue creada para publicación pública. No contiene cuestionarios de clientes, puntuaciones reales ni la metodología privada de auditoría de Blastup. Ejecuta las pruebas con node --test.

## English

Generic 25-question operational self-assessment by Blastup Partner. It covers processes, data, tools, team and measurement.
